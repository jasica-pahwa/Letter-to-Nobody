# Letters to Nobody

A console-based Java application built using Object-Oriented Programming.

## About the Project

Letters to Nobody is an anonymous letter-sharing experience inspired by messages placed inside bottles and released into the ocean. Users can write letters, discover letters, and keep meaningful ones in a personal collection.

## Planned Features

- Release a letter with a mood and category
- Discover a random letter from the ocean
- View letters written by the current user
- Save favourite letters
- Browse letters by mood or category
- Delete a letter

## Technologies

- Java
- Object-Oriented Programming (OOP)
- Java Collections (planned)
- File handling for data persistence (planned)

## How to Run

Compile the Java files:

```bash
javac *.java
```

Run the application:

```bash
java Main
```
